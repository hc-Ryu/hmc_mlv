## VERIFIED CODE FACTS (I read the actual source; treat these as ground truth)
1. class CGDN17(usv18.CGDN) is defined at AI_design_v1_2.py LINE 135. ASWC_STAGE1_END = 100 is at LINE 907. So the constant block placement in Sec 1 puts T_MIN_V13/DELTA_SCALE_V13 about 770 lines AFTER the class body that must reference them as class attributes (Sec 3.1). Class bodies execute at import time -> NameError.
2. In CGDN17.forward(): delta_t_raw = self.leaky_tanh(delta_t_raw) * self.DELTA_SCALE, then group-mean pooled into delta_t_part, then delta_t_part = delta_t_part * thickness_gate where thickness_gate = usv18.thickness_gate_value(epoch) = sigmoid(0.6*(epoch-128)). The Sec 3.4 reachability assert does NOT include this multiplier, and also assumes delta can equal exactly +/-DELTA_SCALE.
3. leaky_tanh(x) = 0.95*tanh(x) + 0.05*x/3. Unbounded (linear leak), so |delta| can exceed DELTA_SCALE, but reaching tanh ~ 1.0 needs large net_out.
4. compute_saturation_loss(delta_t_part, delta_scale, knee=0.9) = mean(relu(|delta| - 0.9*delta_scale)^2). With D=10, knee=9.0. Reaching the range endpoints requires |delta| about 10 > 9, i.e. exactly the region l_sat penalizes.
5. The optimizer in run_training_multi() has groups named 'main', 'thickness_decoder', 'gate_params' built from variables main_params, thick_params, gate_params. There are NO variables named coord_params or thickness_params anywhere in the file. Sec 5.2's rebuild snippet references undefined names, and 'main' mixes the coordinate decoder with the GNN trunk.
6. l_sparse = z_open[:, CANDIDATE_PARTS].mean() and contrib_entropy = (usv18.ALPHA_ENT * gate_multiplier) * entropy both exist in train_step_multi() as described. w_sparse_effective = weights['w_sparse'] * gate_multiplier; gate_multiplier = sigmoid(SPARSE_K*(TAU_GATE - mp_rel_err)).
7. report_design_comparison() line 712 has frac = torch.clamp((t_init-t_min)/(t_max-t_min), 1e-4, 1.0-1e-4) and line 718 exists_cand = (state != STATE_DELETED) & (z_gate[:, cand_idx] > 0.5) -- both as the doc states.

9. target_area defaults to the INITIAL cross-section area (24,056.9), and l_mass = relu(area/target_area - 1)^2 -- a ONE-SIDED penalty that is exactly ZERO for any area below the initial. So with W_SPARSE=0 there is NO gradient pressure to reduce area below baseline; the mass term only punishes exceeding it.
