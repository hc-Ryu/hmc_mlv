## 0. 사용자 결정 사항

1. **블록 종속 이동 B1 채택** — 같은 파트·같은 섹션에서 이어진 고정 노드를 하나의 블록으로 묶고, 블록은
   **학습 변수 없이** 두께 변화만큼 y로 평행 이동한다(매 forward, 미분 가능). → 학습 후 강체 이동 제거.
2. **Outer(#00)–Patch4(#10) 플랜지 접합 신설 — Patch4 기준 양쪽 끝 3개 노드씩**
   (Patch4 pt 1/2/3 ↔ Outer pt 9/10/11, Patch4 pt 12/13/14 ↔ Outer pt 20/21/22).
3. **Patch4 중앙(pt 4–11) = A1 Outer 상대 좌표** — Outer와의 간극 g ≥ 0만 학습한다(§4.3).
4. **g 정규화 = 기존 앵커 항에 편입** — Patch4 중앙 노드의 `l_anchor` 기여를 절대 이동량² 대신 g²로 바꾼다
   (`w_anchor = 0.02` 그대로, 신규 하이퍼파라미터 없음, §4.3).
5. **[개정] Patch1 중앙(pt 2–11)도 Plate pt 11–20 상대 좌표(A1)** — v23 1차 스모크(120 epoch)에서 자유 노드였던
   Patch1 중앙이 Plate를 최대 0.46mm 파고들어(sec 14, 109개 지점) Patch4와 같은 구조로 앞당겨 적용했다.
   (Plate, Patch1) collision 쌍도 구조적으로 관통 불가 → 통째로 제외.

## 1. 문제 정의

### 1.1 현재 세 장치가 각각 무엇을 기준으로 동작하는가

| 장치 | 판단 기준 | 위치 |
|---|---|---|
| 학습 중 좌표 고정 | `_FIX_MASK_TABLE` (part, point) 정적 표 → `fix_x/fix_y` | `usv26._build_fix_mask_table()` |
| collision loss 면제 | `ff_mask` = **점이 고정 AND 투영 세그먼트 양 끝이 고정** | `usv26.build_collision_spec(fix_mask=…)` |
| 접합 간극 정렬 | `FLANGE_PAIR_SPEC` → 학습 후 Stage4 직전 floor별 **파트 전체 y-only 강체 이동** 1회 (Outer 앵커 → Plate → Inner/Patch1–3, Patch4는 Outer와 동일 이동) | `compute_rigid_shift()`, `apply_final_flange_alignment()` |

`FLANGE_PAIR_SPEC` 등록 여부는 collision 면제에도, 학습 중 좌표에도 영향이 없다(v1.17에서 두께 연동 오프셋 층 제거 이후). 학습 중 플랜지 노드는 움직이지 않고 두께만 바뀌므로 접합 간극이 Δ((t_a+t_b)/2)만큼 어긋나며, 이것을 학습 후 강체 이동 1회가 맞춘다.

### 1.2 기존 20쌍이 문제없던 이유 = 우연히 전부 "고정–고정"

| 파트 | 고정 point (`_FIX_MASK_TABLE`) |
|---|---|
| Outer | 1–5, 26–30 (crown/벽 6–25 자유) |
| Plate | 1–3, 7–10, 21–24, 28–30 (4,5,6,25,26,27 해제, v1.16) |
| Inner | 1–3, 16–18 |
| Patch1 | 1, 12 |
| Patch2 / Patch3 | 전부 (3점) |
| **Patch4** | **없음 (14점 전부 자유)** |

- `FLANGE_PAIR_SPEC` 20쌍은 전부 양쪽 고정이라 `ff_mask`로 자동 면제됐다.
- 실측(초기 형상 v8, 15섹션): 현재 `ff_mask`로 면제되는 (점, 세그먼트) 항목 **1,049개는 전부 접합 쌍 또는 3겹 종속 쌍(Inner–Patch2/3)** 이고, 비접합 항목은 0개다 → 면제 기준을 "접합 등록"으로 바꿔도 잃는 항목이 없다.
- **Outer–Patch4는 첫 "자유–자유" 접합**이다: (1) 현 규칙으로 collision 면제 불가, (2) 접합 위치가 경사 벽이라 y-only 강체 이동으로 정렬 불가.

## 2. 설계 원칙

1. **접합은 운동학적 구속이다** — 접합된 노드는 독립 좌표를 갖지 않고 호스트 + 두께 연동 오프셋으로 매 forward 계산된다(고정 노드 여부와 무관).
2. **평탄 플랜지 = 블록 y 평행 이동(B1)**, **경사면·덧판 접합 = 법선 종속 이동** — 접합면 기하에 맞는 자유도를 쓴다.
3. **노드 하나는 정확히 한 구속에만 속한다** — v1.15 테이퍼 중첩(한 노드가 여러 쌍의 오프셋을 동시에 받음) 재발 방지.
4. **collision 면제 기준 = 접합 등록**, 면제는 접합된 점·세그먼트 단위로만. 비접합 영역과 제3 파트 쌍은 그대로 검사.
5. **목표 간극 = 초기 설계 간극(gap0) 보존** — v1.22 §5와 같은 기준. 두께 변화분만 오프셋으로 반영한다.
6. **학습이 보는 형상 = 최종 출력 형상** — 학습 후 보정 단계를 두지 않는다.

## 3. 제안 A — 블록 종속 이동 (B1)

### 3.1 블록 정의

같은 파트·같은 섹션에서 연속한 고정 노드 = 1블록. 초기 형상 v8 실측: **블록 내 y 편차 0.0000 mm (전 15섹션)** — 모두 평탄 밴드라 y 한 값으로 접합 간극을 정확히 맞출 수 있다.

| 파트 | 블록 | 접합 상대 블록 | 블록 y 이동량 (B1) |
|---|---|---|---|
| **Plate (기준)** | [1–3], [7–10], [21–24], [28–30] | — | **0 (datum)** |
| Outer | [1–5], [26–30] | Plate [1–3], [28–30] | **+Δ((t_O + t_P)/2)** |
| Inner | [1–3], [16–18] | Plate [7–9], [22–24] | **+Δ((t_P + t_I)/2)** |
| Patch2 | [1–3] | Plate [22–24] | **−Δ((t_P + t_2)/2)** |
| Patch3 | [1–3] | Plate [7–9] | **−Δ((t_P + t_3)/2)** |

- Δ(·) = 현재 값 − 초기 형상 값. 부호는 초기 형상의 적층 방향(Outer·Inner는 Plate 위, Patch2/3은 아래)으로 고정.
- 두께는 **t_raw**(게이트 적용 전 제조 두께)를 쓴다 — 게이트가 꺼지는 중간 상태에서 형상이 흔들리지 않게 하고, 삭제된 섹션은 어차피 Mp·collision에서 빠진다.
- Patch1 양 끝(pt 1, 12)은 블록이 아니라 법선 종속 이동(§4.2)으로 옮긴다 — Plate pt 10/21이 경사면 시작점이라 y-only로는 간극이 맞지 않는다(증상 3).

### 3.2 기준(datum)을 Plate로 두는 이유

- Plate는 현재도 고정 노드가 가장 많은 파트이고, Plate 블록을 움직이지 않으면 **Plate는 지금과 완전히 같은 동작**이다(변경 최소).
- 초기 형상 생성 규칙(v7/v8 `make_initial_section_v*.py`: "Inner Plate 바닥을 고정점으로 두고 다른 파트를 접합 간격 보정")과 같은 기준이다.
- Mp는 전체 평행 이동에 불변이고 상대 위치만 의미가 있으므로, v1.17 강체 이동의 "Outer 앵커"와 결과적으로 같은 상대 배치를 만든다.
- 3겹 종속 쌍(Inner–Patch2/3, 사이 Plate)은 Inner가 +Δ, Patch가 −Δ로 움직이므로 간극이 **자동으로 Plate 두께**가 된다 — `FLANGE_SANDWICH_DERIVED_SPEC`의 유도와 같다.

### 3.3 v1.15 문제(테이퍼 중첩·꺾임)를 피하는 이유

- 블록 안의 노드는 모두 같은 양만큼 움직이고, 노드 하나는 한 블록에만 속한다 → 중첩 없음.
- 블록과 이웃 자유 노드 사이의 변화는 자유 노드가 decoder로 흡수한다. Plate 전이 구간(4,5,6,25,26,27)을 v1.16에서 해제해 둔 것이 정확히 이 완충 역할을 한다(다만 B1에서는 Plate가 datum이라 Plate 쪽 단차는 생기지 않고, Outer pt 6, Inner pt 4/15 등 상대 파트 쪽 자유 노드가 흡수).
- 주 파트 두께는 전 섹션 공통(pooled)이라 블록 이동량도 섹션 간 같다 → 섹션 간 연속성 손실에 영향 없음. Patch는 run별 두께라 run 경계에서만 차이가 난다.

### 3.4 이동량 규모 (v1.22 최종 두께로 환산)

| 접합 | 초기 t (mm) | 최종 t (mm) | 블록 이동량 |
|---|---|---|---|
| Outer–Plate | 2.3 / 1.6 | 2.500 / 2.429 | +0.51 mm |
| Plate–Inner | 1.6 / 1.6 | 2.429 / 2.500 | +0.86 mm |
| Plate–Patch2 / Patch3 | 1.6 / 1.6 | 2.429 / 0.705 | −0.03 mm |
| (참고) Plate–Patch1 끝 | 1.6 / 1.4 | 2.429 / 1.31–2.16 | 법선 +0.37–0.80 mm |
| (참고) Outer–Patch4 끝 | 2.3 / 1.4 | 2.500 / 2.499 | 법선 +0.65 mm |

현재 강체 이동의 가드(클램프 6.0 mm / abort 3.0 mm)에 비해 충분히 작다.

## 4. 제안 B — 법선 종속 이동 (경사면·덧판 접합)

### 4.1 공식 (호스트 국소 좌표계 기준 초기 오프셋 보존 + 두께 변화분)

슬레이브 노드 s, 호스트 노드 m:

```
p_s = p_m + R_m · v0_local + σ · n_m · Δ((t_m + t_s)/2)
```

- `v0_local`: 초기 형상의 (p_s − p_m)을 호스트 노드 국소 좌표계(접선, 법선)로 표현한 상수 — gap0와 점-점 오프셋(Patch1 끝의 +0.91 mm 같은 경우)을 그대로 보존한다.
- `R_m`, `n_m`: 현재 호스트 형상의 국소 좌표계와 법선(인접 두 세그먼트 법선의 정규화 평균, 끝점은 한쪽, `eps` 정규화). 호스트 벽이 회전해도 오프셋이 같이 회전한다.
- `σ`: 초기 형상에서 정한 부호(슬레이브가 호스트의 어느 쪽에 있는지), 학습 중 고정.
- 미분: `p_s`는 호스트 좌표와 두 파트 두께의 함수 → 두께를 키우면 슬레이브가 자동으로 밀려나고 그 결과가 Mp에 반영된다.
- 접합면이 평탄하면(블록) 이 공식은 §3의 y 이동과 같아진다 — 블록은 이 공식의 특수한 경우다.

### 4.2 적용 대상

| 접합 | 호스트 | 슬레이브 | 비고 |
|---|---|---|---|
| **Outer–Patch4 (신설)** | Outer pt 9, 10, 11 / 20, 21, 22 (자유 노드) | Patch4 pt 1, 2, 3 / 12, 13, 14 | 사용자 결정. gap0 = 0 (초기 면 접촉) |
| Plate–Patch1 끝 | Plate pt 10 / 21 (Plate 블록 끝, datum) | Patch1 pt 1 / 12 | 블록 대신 법선 이동 — 경사면 점-점 오프셋 보존 |

Outer pt 9–11/20–22는 자유 노드이므로 Patch4 끝은 Outer crown·벽이 학습 중 움직이는 대로 따라간다(현재 v1.22에서 최대 19 mm 이동).

### 4.3 Patch4 중앙(pt 4–11, 비접합) — 채택: Outer 상대 좌표(A1)

```
p_k = p_{Outer, 8+k} + R_m · v0_local,k + σ · n_m · ( Δ((t_O + t_4)/2) + g_k ),   k = 4 … 11
g_k = softplus(ĝ_k) ≥ 0      # ĝ_k: Patch4 중앙 노드의 decoder 출력(법선 성분 1개)을 재해석
```

- 초기 형상 Patch4는 Outer pt 9–22의 법선 offset으로 만들어졌으므로(v5 `make_initial_section`, Patch4 pt k ↔ Outer pt 8+k) 1:1 대응이 자연스럽다. 접합 3+3점은 g = 0으로 고정한 같은 식이다(§4.1).
- 자유도: 중앙 8점은 **법선 간극 g 1개씩만** 갖는다. 접선 방향 위치는 Outer를 따른다(덧판이 Outer 위에서 미끄러지는 자유도는 두지 않음).
- **Outer 관통 방지는 구조적으로 보장**(g ≥ 0) → Outer–Patch4 collision 쌍 **전체 면제**(§5). Patch4–Inner 등 다른 쌍은 그대로 검사.
- **g 정규화 = 앵커 항 편입**: `compute_anchor_loss()`에서 Patch4 중앙 노드의 기여를 `|p − p_base|²` 대신 `g_k²`로 바꾼다. 평균 분모(전 노드 수)와 `w_anchor = 0.02`는 그대로 → 다른 자유 노드가 초기 위치에서 1 mm 벗어날 때와 Patch4가 Outer에서 1 mm 떨어질 때 같은 벌점. 신규 하이퍼파라미터 없음.
  - 효과: Outer가 움직이면 Patch4는 벌점 없이 따라가고(v1.22의 "제자리 남기" 제거), 떨어지는 것만 약하게 억제된다. 붙어 있는 것이 Mp에 유리하면(대개 그렇다) g는 0 근처로 수렴한다.
  - 관찰 후 조정: 최종 g 최대가 0.5 mm를 넘으면 Patch4 중앙 기여에만 배율(×5~10)을 두는 것을 다음 단계에서 검토한다.
- 잔여 위험: Outer가 날카롭게 꺾이는 곳에서 인접 offset끼리 교차 가능(offset ≈ 2.5 mm ≪ crown 곡률 반경이라 가능성 낮음) → 비역전파 진단으로 Patch4 자기 교차·Outer 최소 간극을 epoch 로그에 남긴다.

비교로 검토한 A2(중앙을 자유 노드로 두고 collision 예외 + 부착 힌지 손실 신설)는 절대 좌표 앵커가 남아 "제자리 남기"가 재발하고 손실 항이 늘어나 채택하지 않았다.

**[개정] Patch1 중앙(pt 2–11)도 같은 구조로 적용** — Patch1 pt k ↔ Plate pt 9+k(접합 pt 1/12는 g = 0, 중앙 pt 2–11은 g ≥ 0 학습). 계기: v23 1차 스모크에서 자유 노드였던 Patch1 중앙의 Plate 관통(최대 0.46mm).

## 5. 제안 C — 접합 기준 collision 면제

- `build_collision_spec()`에 `ff_mask`와 같은 형태의 `joint_mask (n_pts, n_segs)`를 만든다: 점이 접합(또는 3겹 종속) 관계인 노드이고, 세그먼트 끝이 그 상대 노드일 때 True.
- `compute_collision_loss_v5()`는 `joint_mask` 항목을 valid에서 제외한다. 블록·종속 노드는 더 이상 "고정"이 아니므로 **`ff_mask`는 `joint_mask`로 대체**한다(§1.2: 현재 면제 1,049개 = 전부 접합/3겹 관계 → 대체로 잃는 항목 0, 새로 Outer–Patch4 끝 6쌍이 추가됨).
- (Outer, Patch4) 쌍은 A1으로 구조적으로 관통 불가 → 해당 키 전체를 spec에서 제외(진단 로그용으로 별도 보관).
- (Plate, Patch1) 쌍도 같은 이유로 제외(§0-5 개정). 비접합 영역(Patch4–Inner, Patch1–Inner, Outer–Inner 등)은 그대로 검사.

## 6. 제안 D — clearance 커리큘럼 예외

현재 커리큘럼은 모든 방향의 clearance를 +0.5 mm로 조인다 — 의도된 접촉면을 벌리고 두께를 깎는 압력이 된다.

- 접합 등록 파트쌍의 남은(비접합) 방향은 `target = max(init_clearance, 0)`(관통만 금지)으로 두고, 나머지 파트쌍만 0.5 mm 목표를 유지한다.
- Outer–Patch4·Plate–Patch1은 spec에서 빠지므로(A1) 자동 해결. 남는 대상은 Outer–Plate·Plate–Inner·Plate–Patch2/3의 비접합 방향.
- 이 예외만의 효과(Mp·두께 변화)를 따로 기록한다.

### 7.2 forward 순서

```
decoder Δ (구속 노드는 0으로 마스킹) → 자유 노드 좌표 확정
  → ① 블록 이동: Plate datum, Outer/Inner/Patch2/Patch3 블록 += ±Δ((t_a+t_b)/2)   [§3]
  → ② 법선 종속: Patch1 끝(호스트 Plate pt 10/21), Patch4 끝(호스트 Outer pt 9–11/20–22)  [§4.1]
  → ③ Patch4 중앙 A1: Outer pt 12–19 상대 + g ≥ 0                                    [§4.3]
  → 반환 (v1.22는 y 클램프 없음)
```

호스트가 먼저 확정된 뒤 슬레이브를 계산한다(①의 Outer 블록 이동 → ②③의 Outer 호스트는 자유 노드라 ①과 독립). 노드 하나는 ①②③ 중 하나에만 속한다.
